# Aplicações PayFlow

Esta pasta contém o código-fonte de todas as aplicações do ecossistema PayFlow:

- `api/`: Backend em ASP.NET Core (.NET LTS) organizado em Clean Architecture / Monólito Modular (`PayFlow.Api`, `PayFlow.Application`, `PayFlow.Domain`, `PayFlow.Infrastructure`, `PayFlow.Contracts`).
- `admin-web/`: Painel administrativo SaaS em Angular (Standalone Components, Signals, Reactive Forms, Tailwind CSS).
- `checkout-web/`: Aplicação pública de checkout white-label em Angular, independente e otimizada para conversão.
