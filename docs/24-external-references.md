# 24 — Referências externas técnicas

Fontes a consultar na implementação, preferindo sempre documentação oficial e a versão do projeto:

- Angular releases: https://angular.dev/reference/releases
- Angular update guide: https://angular.dev/update
- .NET support policy: https://dotnet.microsoft.com/platform/support/policy
- ASP.NET Core docs: https://learn.microsoft.com/aspnet/core/
- EF Core docs: https://learn.microsoft.com/ef/core/
- PostgreSQL docs: https://www.postgresql.org/docs/
- Tailwind CSS: https://tailwindcss.com/docs
- OWASP ASVS/Cheat Sheets: https://owasp.org/

Não copiar snippets sem validar compatibilidade com as versões fixadas no workspace.
